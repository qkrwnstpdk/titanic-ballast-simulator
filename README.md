# 타이타닉 700:1 유리구슬 배치 시뮬레이터

A~F 6개 구역(선수에서 선미 방향)에 유리구슬을 최대 하나씩 배치하고, 1~6개 전체 63가지 조합의 비교용 침수 시간을 계산하는 학습용 프로젝트입니다.

## 실행

- **웹 버전:** `index.html`을 Chrome, Edge, Firefox 등 브라우저로 엽니다. 설치가 필요 없습니다.
- **Python 버전:** Python 3에서 `python titanic_ballast_simulator.py`를 실행합니다.

## 구역

`A — B — C — D — E — F`

A는 선수, F는 선미입니다. 웹 화면에서 구역을 클릭해 배치를 선택하고 결과를 확인할 수 있습니다.

## 기본값

- 모형 건조중량: 110 g
- 유리구슬 1개 질량: 1.31 g
- 기준 침수 한계: 145 g
- 기본 물 유입률: 1.5 g/s

## 모델의 한계

이 프로그램은 검증된 조선공학/유체역학 시뮬레이터가 아니라 비교용 간이 모델입니다. `(기준 침수 한계 − 모형과 구슬의 합산 질량) ÷ 물 유입률`로 기본 시간을 계산하고, 구슬의 선수·선미 방향 분포에 경험적인 보정항을 더합니다. 기울기도 정확한 선체 안정성 계산값이 아닙니다. 실제 침몰시간을 보장하지 않으며, 실험 측정값과 비교하는 학습 도구로 사용해야 합니다.

## GitHub에 공개하는 법

1. GitHub에서 새 **Public repository**를 생성합니다(예: `titanic-ballast-simulator`).
2. 이 폴더의 파일을 저장소 루트에 올립니다. `index.html`이 최상위 폴더에 있어야 웹 배포가 간단합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**, Branch `main`, Folder `/(root)`를 선택하고 저장합니다.
5. 배포가 끝나면 같은 Pages 화면에 웹 주소가 나타납니다.
